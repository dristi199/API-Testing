# DummyJson- API Manual Testing
## Project Overview

Manual API testing project performed on the DummyJSON REST API using Postman.

## Tools Used
- Postman
- Excel / Google Sheets
- GitHub
## Testing Performed
- Functional Testing
- Smoke Testing
- Positive & Negative Testing
- Status Code Validation
- Response Validation
## API Modules Tested
- Products
- Users
- Authentication

## QA Documents
- Test Plan
- Test Cases
- Bug Report
- Test Execution Report
- Postman Screenshots
## Objective

To verify API functionality, validate responses and status codes, identify defects, and document the testing results.
